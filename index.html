Privacy Policy

Official Privacy Policy and Data Practices for the NOVA Discord Bot (NOVA-CREATIONS V2)

Effective Date: November 16, 2026 Last Updated: November 16, 2026 Version: 2.0.0

Summary of Core Commitments

NOVA is an autonomous security, moderation, anti-nuke, and utility bot. We do not sell, rent, monetize, or broker user data. We do not store message content, private DMs, or voice audio. Message content is processed in volatile memory in real time solely to execute requested commands and enforce server safety rules (AutoMod / anti-spam), and is immediately discarded.

1. Introduction & Scope

This Privacy Policy explains how NOVA ("the Application", "the Bot", "we", "us", or "our"), operated by the PROJECT.BOTS team, collects, uses, processes, and protects information when you invite, interact with, or utilize NOVA within your Discord server or via direct interactions.

By adding NOVA to your Discord server or using its features, you agree to the collection and handling of data in accordance with this Privacy Policy and Discord's Terms of Service and Developer Policy.

2. Information We Collect

NOVA only collects and stores data strictly necessary to fulfill its defensive security, moderation, administrative, and utility features. All stored data is tied to unique numeric Discord identifiers.

3. Message Content & Transient Processing

NOVA requires the Message Content privileged intent solely for real-time, in-memory operations:

  • Prefix Command Invocation: Detecting messages starting with the server's configured command prefix (default &) to parse command names and command parameters.
  • Automated Moderation (AutoMod): Scanning incoming message text against guild-configured prohibited words and regex patterns to filter toxicity and offensive content.
  • Anti-Spam & Anti-Flood Heuristics: Evaluating message frequency, duplicate character flooding, excessive caps, and mass mentions to prevent raid attacks.
  • Link-Only Channel Protection: Verifying whether messages in designated "Do Not Chat" media/link channels contain required links.

Crucial Clarification: Raw message content is evaluated in volatile memory and is never written to our persistent database or disk. Once a message is verified or a command is dispatched, the message content is released from memory. We do not maintain historical logs of message contents.

4. How We Use Information

We process the collected data strictly for the following purposes:

  • Enforcing server protection rules, anti-raid mechanisms, and anti-nuke safeguards.
  • Restoring deleted channels and roles through the autonomous Self-Heal engine when an unauthorized nuke event occurs.
  • Maintaining accurate moderation case ledgers and administrative logs.
  • Dispatching server welcome and goodbye announcements.
  • Fulfilling scheduled user reminders and birthday notifications.
  • Displaying real-time server statistics (member counts, role counts).

We do NOT:

  • Sell, trade, or monetize any user or server data under any circumstance.
  • Use Discord user data or message content to train machine learning (ML) or artificial intelligence (AI) models.
  • Track, profile, or analyze user activity across multiple Discord servers.
  • Serve third-party advertisements or trackers.

5. Data Storage, Security & Retention

Data Storage: Data is persisted in an isolated local SQLite database running on dedicated hosting infrastructure. Cryptographic tokens and administrative secrets are encrypted at rest using AES-256-GCM encryption.

Data Retention:

  • Active Server Data: Stored for as long as NOVA remains in the server to ensure ongoing configuration and security enforcement.
  • Moderation Case Logs: Retained for the historical record of the respective server's administration until deleted by server administrators or upon server removal.
  • Scheduled Reminders: Automatically purged from storage once delivered or cancelled.
  • Guild Removal: When NOVA is kicked or removed from a Discord server, server-specific configuration records become inactive and are eligible for scheduled deletion.

6. Third-Party Sharing & External Services

NOVA does not share your data with external third parties, marketing services, or analytical aggregators. The only third-party infrastructure involved is:

  • Discord Inc.: All bot traffic flows through Discord's official Gateway and REST APIs pursuant to Discord's Developer Terms.
  • Lavalink Audio Node: Audio streaming operations connect to an internal, self-hosted Lavalink instance to decode audio tracks. Audio streams are not recorded or saved.

7. User Rights & Data Deletion Requests

In accordance with Discord Developer Policies and applicable data protection regulations (such as GDPR and CCPA), users and server administrators have the following rights:

  • Right to Know: You may request information on what data NOVA holds regarding your server or user ID.
  • Right to Deletion (Right to Erasure): You may request the complete deletion of all records associated with your Discord user ID or Discord server.

How to Request Data Deletion:

To request permanent deletion of your server or personal data, you can:

  • Join our official Discord Support Server and open a support ticket under Data Privacy Request.
  • Server administrators can use the built-in configuration reset commands (such as &security reset and backup deletion tools) to clear stored configurations directly.

Requests submitted through our support server are processed within 30 days of verification.
